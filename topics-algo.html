一、复杂度分析

复杂度衡量算法用时 / 内存随数据规模 n 增长的趋势。算大 O 时：只保留与规模有关的项、忽略常数与系数、只留最高次项。竞赛默认按最坏时间复杂度评估。

复杂度含义大致能过的 n（约 1e8 次操作/秒）
O(1)常数不限
O(log n)对数（折半、数位拆分）≤ 10¹⁸
O(n)线性≤ 10⁸
O(n log n)排序、二分套循环≤ 2×10⁶
O(n²)双重循环、简单排序≤ 5000
O(n³)三重循环≤ 500
O(2ⁿ)子集 / 回溯≤ 20
O(n!)全排列暴力≤ 10
超时经验线：普通评测机每秒约做 10⁸ 次基本操作。把「复杂度 × n 的量级」估一下，超过 1e8 大概率 TLE。例如 O(n²) 配 n=10⁶ 就是 10¹²，必然超时。

空间复杂度：主要看数组开多大。int 4 字节、long long 8 字节；256MB 约能开 6×10⁷ 个 int。大数组先算一下字节数，别盲目开大导致 MLE。

二、排序

排序是最基础的预处理。基于比较的排序下界是 O(n log n)；计数排序等非比较排序可达 O(n + w)（w 为值域）。

排序思想平均复杂度一句话适用
选择排序每轮选最小放前面O(n²)教学理解，竞赛基本不用
冒泡排序相邻两两交换把大的冒到后面O(n²)近乎有序的数据、稳定
插入排序把新元素插入前面已排好的序列O(n²)数据基本有序时极快
计数排序按值域开桶统计个数O(n + w)值域小且离散度低时
STL sort底层快速排序 + 插入 + 堆排序混合O(n log n)竞赛默认，随手用
结构体排序自定义 cmp 多关键字O(n log n)多条件排名类题目
稳定性：冒泡 / 插入 / 计数 / 归并是稳定的；选择 / 快排 / 堆排序不稳定。需要保持相等元素相对顺序时用 stable_sort。

STL sort 与结构体排序（可复制模板）

#include <bits/stdc++.h>
using namespace std;

struct Student {
    int total;      // 总分
    int chinese;    // 语文分
    int id;         // 学号
} a[100005];

bool cmp(Student x, Student y) {              // 自定义比较器
    if (x.total != y.total) return x.total > y.total;        // 总分降序
    if (x.chinese != y.chinese) return x.chinese > y.chinese; // 语文降序
    return x.id < y.id;                                       // 学号升序
}

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i].total >> a[i].chinese >> a[i].id;

    int b[8] = {0, 5, 2, 9, 1, 5, 6};
    sort(b + 1, b + 7);                          // 默认升序
    sort(b + 1, b + 7, greater<int>());         // 降序

    sort(a + 1, a + n + 1, cmp);                 // 结构体多关键字排序
    for (int i = 1; i <= n; i++)
        cout << a[i].id << " " << a[i].total << "\n";
    return 0;
}

区间是左闭右开：sort(a+1, a+n+1) 排 a[1..n]；0 起数组写 sort(a, a+n)。pair 自带字典序比较，可直接 sort。

三、枚举

枚举就是把所有可能答案暴力试一遍。关键是控制枚举范围：n 决定能用哪种枚举。

方式思想适用 / 规模
循环枚举直接 for 循环把所有情况跑一遍单层 / 双层能覆盖；n 较大时用不上
二进制枚举用一个整数的每一位表示「选 / 不选」子集问题，n ≤ 20，O(2ⁿ)
排列枚举next_permutation 生成全排列全排列 / 顺序相关，n ≤ 10
枚举优化缩小枚举范围、剪枝、只枚举必要变量减少常数与无用分支

二进制枚举子集（可复制模板）

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; cin >> n;                  // 一般 n <= 20
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int mask = 0; mask < (1 << n); mask++) {   // 枚举所有 2^n 个子集
        for (int i = 0; i < n; i++)
            if (mask >> i & 1)        // 第 i 个元素被选中
                cout << a[i] << " ";
        cout << "\n";
    }
    return 0;
}

排列枚举一行搞定：sort(a, a+n); do { ... } while(next_permutation(a, a+n));（先 sort 才能枚举全）。枚举优化：能从数据范围倒推枚举量，提前 break、固定一个变量枚举另一个、把无关变量移出循环。

四、递归与递推

递归递推
方向大问题拆成小问题，自顶向下从初值出发，自底向上算到大问题
写法函数调用自己for 循环填表
注意要有终止条件、防栈溢出要先确定初值与转移顺序

递归三要素：① 终止条件（Base Case，防止无限递归）；② 递推关系 f(n)=…；③ 向终止条件靠近的自调用。

记忆化递归（可复制模板）

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const ll MOD = 1e9 + 7;
const int N = 100005;
ll memo[N];

ll fib(int n) {
    if (n == 1 || n == 2) return 1;
    if (memo[n] != -1) return memo[n];          // 算过就直接返回
    return memo[n] = (fib(n - 1) + fib(n - 2)) % MOD;
}

int main() {
    memset(memo, -1, sizeof(memo));             // 备忘录初始为 -1
    int n; cin >> n;
    cout << fib(n) << "\n";
    return 0;
}
记忆化思想：用数组记下已算过的子问题答案，避免重复计算。朴素斐波那契是 O(2ⁿ)，加记忆化后变成 O(n)——这也是动态规划的雏形。

五、模运算

结果可能很大时，题目常要求「对 p 取模」。核心公式如下（细节、逆元、快速幂见 数学专题）：

运算取模公式注意
加(a+b) % p = (a%p + b%p) % p先取模再相加
减(a-b) % p可能为负，写 ((a%p - b%p) % p + p) % p
乘(a×b) % p两个模数相乘可能爆 int / long long，注意开 ll 或用快速乘
除—不能直接取模，要用乘法逆元（见数学专题）
负数取模统一写法：((x % p) + p) % p。

六、前缀和

前缀和是最常用的「预处理换查询」手段：预处理 O(n)，之后每次区间查询 O(1)。本质是用「一段前缀减另一段前缀」得到任意区间信息。

6.1 核心概念

什么是前缀和？即数列前 i 项的和：

prei = a1 + a2 + ⋯ + ai

递推关系：pre[i] = pre[i-1] + a[i]（注意数据范围是否需要 long long）。

6.2 一维前缀和

性质：区间和查询。求区间 [l, r] 内数字之和：

ans = prer - prel-1

证明：prer = a1+⋯+al-1+al+⋯+ar，prel-1 = a1+⋯+al-1，两式相减即得 al+⋯+ar。

同理可拓展至：前缀积（乘法）、前缀异或（^）、区间内某类数个数（把符合条件的标 1，其余标 0，再前缀和）。

6.3 二维前缀和

pre[i][j] 是左上角 (1,1) 到 (i,j) 的子矩阵和。递推（容斥）：

pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]

查询子矩阵 (x1,y1)~(x2,y2)：大减小、加回重叠。

ans = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]

6.4 模板代码

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N = 1005;
int a[N]; ll pre[N];            // 一维
int g[N][N]; ll s[N][N];        // 二维

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i - 1] + a[i];           // 预处理 O(n)
    }
    int l, r; cin >> l >> r;
    cout << pre[r] - pre[l - 1] << "\n";       // O(1) 区间和

    int m; cin >> n >> m;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            cin >> g[i][j];
            s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + g[i][j];
        }
    int x1, y1, x2, y2; cin >> x1 >> y1 >> x2 >> y2;
    ll ans = s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1];
    cout << ans << "\n";
    return 0;
}

七、差分

差分是前缀和的逆运算。当需要对数组的多个区间同时加上同一个数时，直接逐个改是 O(n)，用差分数组可以做到 O(1) 完成一次区间修改，最后再做一次前缀和还原。

7.1 核心概念

定义差分数组 d[i] = a[i] - a[i-1]（约定 a[0]=0）。对 d 做前缀和即可还原出原数组 a。

区间加 v：给 a[l..r] 都加上 v，等价于差分数组上：

d[l] += v,    d[r+1] -= v

做完所有区间修改后，对 d 做一次前缀和，即得到最终的数组 a。

7.2 二维差分

给子矩阵 (x1,y1)~(x2,y2) 都加 v，对应差分数组操作（容斥）：

d[x1][y1] += v;
d[x2+1][y1] -= v;
d[x1][y2+1] -= v;
d[x2+1][y2+1] += v;

7.3 模板代码

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int N = 100005;
int a[N], d[N];

int main() {
    int n, m; cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        d[i] = a[i] - a[i - 1];            // 构造差分数组
    }
    while (m--) {
        int l, r, v; cin >> l >> r >> v;
        d[l] += v;                          // O(1) 区间加
        d[r + 1] -= v;
    }
    for (int i = 1; i <= n; i++) {
        a[i] = a[i - 1] + d[i];            // 前缀和还原
        cout << a[i] << " ";
    }
    return 0;
}
什么时候用差分？题目描述里有「对 [l,r] 每个元素加上 v」这类区间修改操作，且修改次数多、最后才查询——就是差分的信号。

八、二分查找

二分把查找范围每次砍半，O(log n) 找到目标。前提：数组已有单调性（升序或降序）。竞赛中二分不仅是查数组，更常用在「二分答案」——把一个求最优解问题转化为「判定某个答案是否可行」。

8.1 整数二分模板

// 在升序数组 a[1..n] 中找第一个 >= x 的位置
int l = 1, r = n;
while (l < r) {
    int mid = (l + r) / 2;
    if (a[mid] >= x) r = mid;   // 答案在左半
    else l = mid + 1;           // 答案在右半
}
// 结束时 l == r，即所求位置

8.2 STL 二分函数

函数作用
lower_bound(a+1, a+n+1, x)第一个 ≥ x 的位置
upper_bound(a+1, a+n+1, x)第一个 > x 的位置
binary_search(a+1, a+n+1, x)数组中是否存在 x（返回 bool）

8.3 二分答案

当问题满足「答案越大/越小，可行性单调变化」时，可以二分答案。写一个 check(x) 函数判断 x 是否可行，然后二分找最大/最小可行值。

// 模板：求最小的 x，使得 check(x) 为 true
int l = 最小可能值, r = 最大可能值;
while (l < r) {
    int mid = (l + r) / 2;
    if (check(mid)) r = mid;    // mid 可行，尝试更小
    else l = mid + 1;           // mid 不可行，必须更大
}
cout << l << "\n";
二分答案常见场景：最大值最小化（跳绳/切绳子）、最小值最大化（跳石头）、判定可行性。关键是想清楚 check(x) 怎么写。
