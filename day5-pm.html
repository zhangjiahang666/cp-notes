① RSA 解密求因子（N = P·Q）

给定 K 次询问，每次给 N、E、D，求正整数 P、Q 满足：

  • N = P × Q
  • E × D = (P-1)(Q-1) + 1
分数做法复杂度数据范围
20 分枚举 P 从 1 到 N，检查 N%P==0O(K·N)极小数据
60 分因数成对，枚举 P 到 √NO(K·√N)N≤1e9（约 3e4）
100 分推导一元二次方程，求根公式O(K)N≤1e18

100 分推导：

  • φ = (P-1)(Q-1) = N - P - Q + 1
  • E·D = φ + 1 → P + Q = N + 2 - E·D
  • P、Q 是方程 x² - (P+Q)x + N = 0 的两根
  • Δ = (P+Q)² - 4N，先判 Δ ≥ 0 再开根号

⚠️ Δ < 0 直接输出无解，不判断会负数开根运行异常。

② 区间取余最大值

给定 n、L、R，求 [L,R] 区间内整数对 n 取余的最大值。

思路：余数序列周期为 n，每周期内 0,1,2,...,n-1 循环递增。

情况答案
区间中包含某个数 ≡ n-1 (mod n)n - 1
不包含 n-1 顶点R % n

复杂度 O(1)，1e9 范围直接过，不能遍历。

③ 带修改的数组查询

两类操作：修改某位置的值；查询某元素排序后的位置。修改 5000 次，查询 2×10⁵ 次。

  • 结构体存 {值, 初始位置}
  • 排序规则：先按值升序，值相同按初始位置升序（稳定排序）
  • 只在修改时重排（最多 5000 次），查询时直接输出位置
  • 不要每次查询都排序或遍历找位置

🛠️ 实操：FC 命令对比大样例

在输出文件所在文件夹地址栏输入 cmd 回车，执行：

FC 我的输出.txt 标准答案.txt

输出「找不到差异」就说明完全一致，不用肉眼逐行对。
